# 🛒 E-Commerce Website - https://e-commerce-zeta-eight-64.vercel.app/

A fully responsive e-commerce website built using **HTML, CSS, and JavaScript**.  
This project showcases modern UI design, responsive layouts, and basic cart functionality.

---

## 🚀 Features

- 🛍️ Product listing with images and pricing  
- 📱 Fully responsive (mobile, tablet, desktop)  
- 🧭 Hamburger menu for mobile navigation  
- 🛒 Shopping cart UI with quantity update  
- 💰 Dynamic subtotal and total calculation using JavaScript  
- 🎨 Modern UI with hover effects and animations  

---

## 🛠️ Tech Stack

- **HTML5** – Structure  
- **CSS3** – Styling (Flexbox, Media Queries)  
- **JavaScript (ES6)** – DOM manipulation & logic
